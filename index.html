Gmail-integrated link protection

Pause. Inspect. Click with more context.

LinkShield helps Gmail users examine individual URLs found in an email. It combines basic URL indicators with URLhaus threat-intelligence results and presents a readable risk assessment inside Gmail.

An assistive security tool — not a guarantee of safety

What LinkShield does

LinkShield adds an analysis step to the email-reading workflow, helping users notice signals that may deserve a closer look.

🔎 Individual link extraction

Finds website URLs in the currently opened Gmail message and presents them separately for analysis.

🧭 Heuristic URL checks

Checks basic indicators such as HTTPS usage, IP-address hosts, the @ symbol and selected suspicious keywords.

🛡️ Threat-intelligence lookup

Queries URLhaus to check whether a URL is listed in its threat-intelligence database.

📋 Readable risk report

Combines available results into a per-link report shown in the LinkShield Gmail add-on.

How it works

A simple flow from an opened email to an informed decision.

1. Open an email

Open a Gmail message containing website links.

2. Choose a link

LinkShield lists detected links and lets you request an analysis for an individual URL.

3. Review the report

The backend checks basic URL indicators and queries URLhaus, then returns a risk assessment.

Important: A URL marked “NOT_LISTED” was not found in the URLhaus database at the time of the check. This does not prove that the URL is safe. LinkShield displays warnings and cannot block Gmail’s native link-click action.

Designed to add context, not certainty

No automated URL check can guarantee that a website is safe. Verify unexpected requests, avoid sharing passwords or verification codes through suspicious links, and use your judgement before visiting a website.
