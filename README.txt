LinkShield static website
Files: index.html (landing page), privacy.html (privacy policy).

Publish using GitHub Pages:
1. Upload index.html and privacy.html to the root of the ns12-design/LinkShield repository (or a dedicated website repository).
2. Open repository Settings > Pages.
3. Choose Deploy from a branch, select main and /(root), then Save.
4. Wait for GitHub Pages to publish. Copy the exact URL shown in Settings > Pages into the Marketplace Application Website URL field.

Before publishing, review the privacy policy against the actual deployed code, hosting/logging configuration, and third-party services. Do not submit until the public site is accessible.
