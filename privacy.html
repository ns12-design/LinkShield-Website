LinkShield Privacy Policy

Last updated: 14 November 2026

LinkShield is a Gmail add-on that analyses individual website URLs found in the Gmail message currently opened by the user. This page describes the data handling intended by the current project implementation.

Information accessed

When a user opens a message with LinkShield, the add-on accesses the current message content to identify website URLs. The add-on also displays the message subject and sender in its interface. The user chooses which detected URL to analyse.

Information sent for analysis

When the user requests an analysis, the selected URL is sent to the LinkShield backend hosted on Render. The backend performs heuristic URL checks and submits the URL to URLhaus for a threat-intelligence lookup. The analysis response is returned to the add-on.

Information not required for URL analysis

The current backend analysis request is designed to send the selected URL, not the full email body, message subject, sender address, Gmail password, or email attachments.

Third-party services

LinkShield relies on Google Apps Script and Gmail for the add-on experience, Render for backend hosting, and URLhaus for threat-intelligence lookups. Those services process data according to their own terms and privacy policies. A URL submitted for analysis is disclosed to the backend and URLhaus.

Storage and retention

The project returns analysis results to the add-on. This policy does not promise that infrastructure providers retain no operational logs. Users should consult the relevant providers’ policies for their retention practices.

Security and limitations

The backend uses an API key to authenticate requests from the add-on. Users should not share credentials or API keys. A URL reported as “NOT_LISTED” by URLhaus is not confirmed safe. LinkShield provides risk indicators and does not block Gmail’s native link-click action.

Contact

For questions about this project, contact the developer using the email address published in the LinkShield Google Workspace Marketplace listing.
